# 🧠 Guia de Gestão do Segundo Cérebro (META)

Este arquivo serve como instrução para futuras sessões de IA para manter a integridade e o estilo deste cofre.

## 🏛️ Estrutura de Pastas
- `00_Inbox/`: Notas brutas, capturas rápidas e arquivos para processar.
- `00_META/`: Instruções de sistema e regras para agentes de IA.
- `10_Literature_Notes/`: Notas de fontes externas (Artigos, Livros, Palestras).
    - `References/`: Notas individuais de autores padrão `[[Sobrenome Ano]]`.
- `20_Permanent_Notes/`: Conceitos atômicos, autorais e destilados.
- `30_MOCs/`: Mapas de Conteúdo (Índices dinâmicos).
- `40_Projects/`: Projetos ativos (ex: Mestrado ITA).
- `90_Assets/`: Templates, imagens e anexos.

## 🖇️ Padrões de Escrita
1. **Atomicidade**: Cada nota permanente deve focar em apenas um conceito.
2. **Links**: Use `[[Link]]` extensivamente para conectar ideias.
3. **Referências**: Toda afirmação técnica deve, preferencialmente, apontar para uma nota em `10_Literature_Notes/References/`.
4. **MOCs**: Sempre atualize o MOC relevante ao criar uma nova nota permanente importante.

## 🎯 Objetivos de Longo Prazo
- Apoiar a pesquisa de Mestrado de [[Flavian Fernandes]].
- Integrar [[MBSE]] com [[Agentic AI]] e [[IA Generativa]].
- Manter rastreabilidade entre a prática (Sistemas Embarcados) e a teoria de sistemas (NASA SE Lifecycle).
