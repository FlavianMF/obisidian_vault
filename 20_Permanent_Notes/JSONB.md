# 📄 JSONB

Tipo de dado no [[PostgreSQL]] que armazena dados JSON em formato binário, permitindo consultas eficientes e indexação de campos dentro do JSON.

## Aplicação no [[birthday_counter]]
- Utilizado para configurações dinâmicas de eventos e perfis de usuários, garantindo flexibilidade no esquema.
