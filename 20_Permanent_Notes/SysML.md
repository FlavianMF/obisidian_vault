# SysML (Systems Modeling Language)

## 💡 Definição
Linguagem de modelagem de uso geral para sistemas complexos. É uma extensão/perfil do [[MBSE|UML]] voltada para [[MBSE|Engenharia de Sistemas]].

## 📊 Diagramas Principais
1. **Estrutura**: Block Definition Diagram (bdd), Internal Block Diagram (ibd).
2. **Comportamento**: State Machine, Activity, Sequence.
3. **Requisitos**: Requirement Diagram.
4. **Paramétricos**: Para análise de performance e restrições.

## ⚠️ Desafios Atuais (Gap de Tradução)
Como notado em [[Yu et al 2024]], [[Agentic AI|LLMs]] têm dificuldade em gerar sintaxe SysML rigorosa a partir de linguagem natural, o que é o foco da sua pesquisa em [[MBSE com Agentic AI]].
