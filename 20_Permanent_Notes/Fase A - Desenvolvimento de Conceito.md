# Fase A - Desenvolvimento de Conceito

## 🎯 Objetivo
Determinar a viabilidade e o mérito de um sistema proposto. Define a arquitetura do sistema e os requisitos de alto nível.

## 📦 Entregáveis Principais
- **Arquitetura do Sistema**: Definida e documentada.
- **Requisitos do Sistema (L1)**: Requisitos derivados dos objetivos da missão.
- **Plano de Gerenciamento de Engenharia de Sistemas (SEMP)**: Como a engenharia será conduzida.

## 🏁 Gate Review
- **System Requirements Review (SRR)**: Valida se os requisitos estão completos e entendidos.
- **System Definition Review (SDR)**: Avalia se a arquitetura proposta é capaz de atender aos requisitos.
