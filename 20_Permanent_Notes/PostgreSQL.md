# 🐘 PostgreSQL

Sistema de gerenciamento de banco de dados relacional de código aberto, conhecido por sua robustez e suporte a recursos avançados.

## Recursos
- Suporte a [[JSONB]] para dados semi-estruturados.
- Extensões poderosas ([[pg_trgm]] para busca textual).
