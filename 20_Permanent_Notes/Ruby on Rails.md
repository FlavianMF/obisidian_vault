# 💎 Ruby on Rails

Framework web baseado na linguagem [[Ruby]], focado na produtividade e felicidade do desenvolvedor através da convenção sobre configuração (CoC).

## Características
- **CoC (Convention over Configuration)**: Muitas decisões são tomadas pelo framework, acelerando o desenvolvimento.
- **MVC (Model-View-Controller)**: Separação clara de responsabilidades.
- **Active Record**: ORM robusto para interação com banco de dados.
- **Ecossistema**: Rico em bibliotecas (Gems).

## Aplicação no [[birthday_counter]]
- Utilizado como framework principal para a aplicação [[birthday_counter]], gerindo API, views dinâmicas e integração WebSocket.
