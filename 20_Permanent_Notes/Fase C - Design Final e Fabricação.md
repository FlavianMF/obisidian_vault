# Fase C - Design Final e Fabricação

## 🎯 Objetivo
Transformar o design preliminar (Fase B) em um design detalhado "pronto para fabricação". Esta fase encerra o processo de design e inicia a criação do hardware e código final.

## 🛠️ Atividades Principais
1.  **Design Detalhado**: Engenharia de detalhe para cada componente (CAD final, roteamento de PCBs, esquemáticos completos).
2.  **Desenvolvimento de Software**: Codificação baseada nos algoritmos validados na Fase B, seguindo padrões de codificação seguros e modulares.
3.  **Unit Testing**: Teste individual de cada módulo de software e componente de hardware.
4.  **Long-Lead Procurement**: Compra de componentes com longo prazo de entrega para evitar atrasos na Fase D.
5.  **Definição de Planos de V&V**: Detalham como cada requisito será verificado (inspeção, análise, demonstração ou teste).

## 📦 Entregáveis Principais
- **Product Baseline**: A definição final do sistema que será fabricado.
- **Critical Design Report**: Documentação exaustiva de todas as decisões técnicas.
- **Software Version Description (SVD)**: Definição da versão do software para integração.
- **ICDs Finais**: Documentos de interface congelados.

## 🏁 Gate Review
- **Critical Design Review (CDR)**: O marco mais importante da engenharia. Demonstra que o design é maduro, atende aos requisitos e tem riscos mitigados o suficiente para iniciar a fabricação em massa ou montagem final.
