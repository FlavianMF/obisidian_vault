# 🔥 Hotwire

Arquitetura para construir aplicações web modernas sem a complexidade de frameworks de JavaScript pesados. É a forma padrão do Rails de lidar com a interface do usuário.

## Componentes
- [[Turbo]]: Entrega fragmentos de HTML pela rede para atualizar páginas sem recarregá-las.
- [[Stimulus]]: Framework de JavaScript para adicionar interatividade baseada em HTML.

## Aplicação no [[birthday_counter]]
- Utilizado para garantir a experiência SPA-like do [[birthday_counter]], minimizando o uso de JS pesado.
