# Capella MBSE

## 💡 Definição
Capella é uma ferramenta open-source de modelagem de arquitetura de sistemas que implementa a metodologia **Arcadia** (ARChitecture Analysis and Design Integrated Approach). Diferente de outras ferramentas [[SysML]], o Capella é focado em guiar o engenheiro através de níveis de abstração claros e estruturados, garantindo uma "fonte única da verdade" (SSoT).

## 🏗️ Níveis de Abstração (Arcadia)
1. **Operational Analysis (OA)**: Foco no domínio do problema e necessidades dos stakeholders. O que eles querem realizar?
2. **System Analysis (SA)**: Define os requisitos do sistema (caixa-preta). O que o sistema deve fazer?
3. **Logical Architecture (LA)**: Decomposição funcional e estrutural independente de implementação técnica. Como o sistema se organiza?
4. **Physical Architecture (PA)**: Design detalhado com componentes físicos, hardware, software e links de comunicação. Como o sistema é construído?
5. **EPBS (End Product Breakdown Structure)**: Estrutura de pacotes de trabalho para aquisição, subcontratação e produção.

## 🛠️ Principais Recursos
- **Methodological Browser**: Guia passo a passo através da metodologia Arcadia.
- **Viewpoints**: Extensões para análises especializadas (Segurança, Performance, Custo) integradas ao modelo.
- **Transição Automática**: Ferramentas para transicionar elementos entre camadas (ex: Funções Operacionais para Funções de Sistema).
- **Geração de Documentação**: Exportação automática de diagramas e tabelas para HTML ou PDF.

## 📊 Entregáveis por Nível
- **OA**: Operational Entity Blank (OEB), Operational Activity Interaction Blank (OAIB).
- **SA**: System Architecture Blank (SAB), Functional Dataflow Blank (FDFB), System Scenario (ES).
- **LA/PA**: Logical/Physical Architecture Blank (LAB/PAB), Logical/Physical Component Exchange.
