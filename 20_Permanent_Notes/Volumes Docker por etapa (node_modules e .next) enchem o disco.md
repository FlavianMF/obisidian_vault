# Volumes Docker por etapa (node_modules/.next) enchem o disco

## Sintoma
O compose por etapa cria volumes `*-be-nm`, `*-fe-nm` e `*-next`. Ninguém os remove. No `projetos_claude`, 87 volumes ocuparam 31G.

## Como medir
Rode um container descartável: `docker run --rm -v <volume>:/v alpine du -sh /v`. Não use `docker system df -v`: com o disco cheio, ele demora minutos.

## Como limpar
- Rode `docker volume rm <volume>`. O Docker recusa remover volume em uso, então a limpeza é segura.
- Se o Docker recusar, pare e remova antes o container que usa o volume.

## Prevenção
Compartilhe os volumes entre etapas ou remova-os ao fim de cada etapa (`docker compose down -v`). Esta sugestão não foi testada.
