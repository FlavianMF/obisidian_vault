# 🎨 Visualização Científica e Resumos Gráficos

Em 2025, o **Graphical Abstract** deixou de ser opcional para se tornar uma ferramenta estratégica de *storytelling* visual, especialmente em Engenharias.

## 🚀 Princípios de Design (Padrão 2025)

1.  **Mensagem Única**: Não tente resumir o artigo inteiro. Foque no principal diferencial ou descoberta (*"the so what?"*).
2.  **Caminho de Leitura Claro**: Fluxo linear (Esquerda para Direita ou Cima para Baixo). Evite padrões em "Z" ou ramificações complexas.
3.  **Texto Mínimo**: Use rótulos de 1-3 palavras. Se o leitor precisar "ler" em vez de "escanear", o gráfico falhou.
4.  **Contraste e Acessibilidade**: O gráfico deve ser legível em tons de cinza e usar paletas seguras para daltônicos (ex: esquemas ColorBrewer).
5.  **Especificações Técnicas**: Mínimo de **300 DPI**. Fonte mínima de **7pt** para garantir legibilidade quando reduzido.

## 🏗️ Padrões de Layout por Tipo de Trabalho
- **Result-First**: Destaque o número ou breakthrough principal no centro.
- **Comparison Panels**: "Proposto vs. Convencional" lado a lado com escalas idênticas.
- **Process Flow**: Para novos algoritmos ou processos de fabricação (3-5 passos com setas claras).
- **System Architecture**: Blocos simplificados (evite desenhos CAD excessivamente detalhados).

## 🛠️ Ferramentas Recomendadas
- **BioRender / Mind the Graph**: Bibliotecas massivas de ícones científicos e de engenharia.
- **Inkscape / Adobe Illustrator**: Para vetores customizados e requisitos EPS rigorosos.
- **Zenodo / GitHub**: Para hospedar a versão vetorial original e dados fonte do gráfico.
