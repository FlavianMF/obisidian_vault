# Projeto birthday_counter

Um projeto web (Birthday Counter Experience) desenvolvido pelo **Hermes Agent** para demonstrar a aplicação de Engenharia de Sistemas no ciclo de vida de software agêntico.

## 📌 Visão Geral
O projeto serve como prova de conceito de que agentes de IA podem seguir rigorosamente as fases de definição de requisitos (Pré-Fase A até Fase B) para criar sistemas complexos e gamificados com alta integridade arquitetural.

## 🧠 Conceitos e Padrões Extraídos
- [[Engenharia de Sistemas Agêntica]]: O uso de SE para guiar o desenvolvimento autônomo.
- **Modelagem de Estados Sistêmicos**: Uso de FSM (Finite State Machines) para gerenciar o ciclo de vida do evento.
- **Gamificação Orientada a Requisitos**: Lógicas de jogo (Memory Geoguessr, Fact or Fiction) derivadas diretamente de metas de engajamento no PRD.
