# Fase B - Definição Preliminar

## 🎯 Objetivo
Definir o sistema no nível de subsistemas e interfaces. É a transição da formulação para a implementação.

## 📦 Entregáveis Principais
- **Design Preliminar**: Descrição técnica detalhada dos subsistemas.
- **Interface Control Documents (ICDs)**: Definição de como os subsistemas se conectam.
- **Requisitos de Subsistemas (L2)**: Decomposição dos requisitos do sistema.
- **Protótipos de Baixa/Média Fidelidade**: Para prova de conceito.

## 🏁 Gate Review
- **Preliminary Design Review (PDR)**: Demonstra que o design preliminar atende a todos os requisitos com risco aceitável.
