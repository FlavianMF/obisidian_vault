# 📄 Impact of Artificial Intelligence on Software Engineering Phases and Activities (2013–2024)

## 📌 Summary
A quantitative analysis of 120 research papers using a **Zero-Truncated Poisson (ZTP) model** to measure AI's impact on the SE lifecycle. It identifies statistically significant improvements in both accuracy and efficiency.

## 📊 Key Quantitative Findings

| SE Phase | Accuracy Impact | Efficiency Impact | Notable Quantitative Detail |
| :--- | :--- | :--- | :--- |
| **Planning** | Significant Improvement | Moderate | Enhanced decision-making accuracy. |
| **Requirements** | **Marked Improvement** | **Marked Improvement** | **40% reduction** in manual effort; **0.61** efficiency estimate (p < 0.0001). |
| **Design** | Moderate | Significant Improvement | Refined architecture and re-modularization. |
| **Development** | Significant Improvement | Moderate | Faster code generation; reduced modifications. |
| **Testing** | Significant Improvement | Moderate | Improved defect detection and fault prediction. |

## 🚀 Key Mechanisms
- **Automated Traceability:** Tools like *Trustrace* reduce manual mapping effort by 40%.
- **NLP in Requirements:** Converting user stories directly to UML diagrams.
- **Predictive Analytics:** Handling count data and predicting fault occurrences.
