# ASD-STE100 output style for Claude Code (gist)

## 📝 Resumo

- Output style com `keep-coding-instructions: true`.
- Precedência: instrução mais específica do usuário, do projeto ou da skill vence o estilo.
- Isenta código, citação e texto em que a redação exata importa.
- Usa `CONTEXT.md` como glossário do projeto, se existir.
- Os limites valem por frase, não por resposta. Clareza vence brevidade. Nenhum fato ou ressalva cai para cumprir um limite.

## Confiabilidade

Bom modelo de isenções e precedência.
