# Skill: Academic-Evidence-Mapper

## Comportamento
Fundamentação científica obrigatória para decisões técnicas.

## Regras
1. **Evidência Proativa**: Ao propor uma arquitetura ou método novo, o agente deve buscar evidência acadêmica (Scholar, arXiv, NTRS).
2. **Citação**: Seguir a [[Skill - Ingestão de Notas de Literatura]] para qualquer citação.
3. **Justificativa**: O agente deve ser capaz de responder: "Qual é a base acadêmica para essa decisão?"
